# DSP submission — completion checklist

## Before the completion link arrives
- [ ] Watch for the DSP email "complete your submission" (also check spam); note its deadline.
- [ ] If no email within 3 business days, contact the DSP editorial office / Elsevier support
      quoting transfer `SIGPRO-D-26-04464`.
- [ ] Do not open the completion flow until the v3 files are ready; if the deadline is short,
      request an extension in writing (the transfer is recorded).

## When completing the submission (portal)
- [ ] Replace the inherited title with: "Fragile Authentication of PDF Signatures via Bit-Exact
      Quantization Index Modulation on Vector Geometry".
- [ ] Replace the inherited abstract with the v3 abstract.
- [ ] Upload the v3 manuscript PDF (not the v2.0 transfer file).
- [ ] Upload highlights and the cover letter.
- [ ] Check author metadata/ORCID; declarations (preprint, patent, no concurrent submission).
- [ ] Confirm the APC is due only on acceptance; request waiver/discount if applicable before
      accepting.
- [ ] Record the new DSP manuscript ID in PUBLICATIONS.md.

## Hard gate
- [ ] `references.bib` audit passes (all citations resolve; no unverifiable entry).
- [ ] Evaluation tables in the manuscript are generated by `paper_v3/eval/` (no hand-typed numbers).
