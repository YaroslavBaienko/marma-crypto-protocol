# IEEE portal answer matrix

Use these rules on the Additional Information page; adapt wording to the current portal form.

| Portal question | Answer when... | Evidence to keep |
|---|---|---|
| Submitted previously to this journal? | `No` only if this exact journal has no prior record. Prior submissions to other journals do not make this a resubmission to this journal. | Portal UUID, prior journal IDs |
| Previously published, in whole or in part? | `Yes` if any public version exists that the form treats as presentation/publication (preprint/author copy may be included). `No` only if no public version exists. | Disclosure PDF, public URLs/DOIs |
| Can provide previously published files? | `Yes` if files are available; upload a statement listing DOIs/URLs and the actual prior file only if the form requires it. | File hashes |
| Identical preprint posted? | `Yes` for an identical public author copy or preprint server copy; list it and do not add it to the reference list. | URL, release tag, same PDF hash |
| Other preprints not prior art? | Usually `No`; related preprints are prior art and should be cited/explained, not excluded. | Citation key, explanation |
| Resubmission/related to a rejected manuscript? | `Yes` if any prior version was rejected or withdrawn anywhere. List venue and manuscript IDs; explain the differences. | Prior-submission statement |
| Extended conference paper? | `Yes` only if a conference paper exists; provide citation and additional contribution. | Conference DOI |
| Other author papers not in references? | `Yes` only for published/accepted/under-review papers not cited; list them. Rejected or unpublished drafts are not "published". | Citation list |
| Code associated? | `Yes` if public or reviewable code exists (GitHub release/archive). Code Ocean is optional unless the form requires it. | Code URL/DOI |
| Data associated/DataPort? | `Yes` only if actually deposited on IEEE DataPort and a DOI/title exists; otherwise `No` (no deposit). | DataPort DOI |
| Human/animal subjects? | `No` when no human/animal data were used. | Ethics statement in manuscript |
| COI/funding? | Match the manuscript's competing-interests/funding statement exactly. | Manuscript declarations |
| Opposed reviewers? | Leave empty unless there is a documented, specific conflict. | None |

## Wording rules

- Never answer `No` to a prior-submission question when a public version exists; the editor can find it.
- Distinguish **formal publication** from **preprint/author copy** in the explanation, but disclose both.
- For scope rejections, state why the new venue fits (specific EDICS and contribution), not just "revised".
- Frozen answers belong in the submission record.
